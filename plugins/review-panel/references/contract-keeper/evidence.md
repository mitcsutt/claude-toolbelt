## Don't flag

- An added optional response field, unless a named consumer is strict: `additionalProperties: false`, a strict deserialiser (CK8, CK9; R12 §4).
- An added request enum value or a widened request input (CK8).
- An added response enum value where the contract is `x-extensible-enum` and every named consumer has a default branch (CK8, CK13).
- A break in an element no consumer uses: COULD with "no consumer found", never BLOCK (CK1).
- `ADD COLUMN … DEFAULT <constant>` on PG ≥11 (CK14).
- CREATE INDEX CONCURRENTLY in a migration marked non-transactional (CK15).
- A break in a MAJOR bump with a deprecation window when consumers are pinned (CK20).
- Behaviour of a dependency, platform or tool that isn't the interface under review: leave it to fact-checker (CK22; R16 F1).
- Re-runs, interrupted DDL, throttling, supervisors: leave them to paranoid-sre (R12 §6).
- "Add a deprecation window" on an internal, single-deploy interface whose consumers all ship in the same commit (doctrine, no evidence).
